RAY CHOICE CENTER — ADVANCED SMART REVIEW STUDIO
=================================================

WHAT THIS VERSION DOES
- Free static website; no API key, server, login, or paid AI service is required.
- Lets a customer select a service, language, optional actual-experience detail, optional highlight, and draft length.
- Generates varied, editable review drafts using local JavaScript phrase combinations.
- Copy button copies the draft. Open Review Page button opens the Google review URL.
- Responsive design for desktop and mobile.

HOW TO USE ON YOUR COMPUTER
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
4. Select a service and language; enter only details that reflect the customer's real experience.
5. Click Generate Review Draft, edit it if needed, then Copy review.
6. Click Open review page and paste the text into Google yourself.

HOW TO PUBLISH FOR FREE
Option 1 — GitHub Pages:
1. Create a repository on GitHub.
2. Upload index.html, style.css, app.js.
3. In repository Settings, open Pages.
4. Select deploy from branch, choose main and /(root), then Save.
5. Use the published Pages URL after deployment finishes.

Option 2 — Vercel:
1. Sign in to Vercel and import your GitHub repository, or upload the project using a supported workflow.
2. For this static website, no environment variables or build command are needed.
3. Deploy and open the generated website URL.

IMPORTANT LIMITATIONS AND REVIEW ETHICS
- This is a template-and-keyword-combination generator, not a generative AI model. It creates variety without API charges.
- It cannot guarantee every generated sentence will be unique.
- The customer must edit the draft to match their genuine experience and decide whether to post it.
- The site does not automatically submit or post Google reviews, and cannot guarantee Google will prefill the review box.
- Do not use it to fabricate experiences, incentivize reviews, or pressure customers to leave positive reviews. Customers should be free to give honest feedback.
- The site uses a Google Fonts import for typography; without internet, it falls back to system fonts.
