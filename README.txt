HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Chrome or Edge.
3. Select the service, language and review length.
4. Optionally enter a true detail about the customer's experience.
5. Click Generate Review. The draft appears in an editable text box.
6. Click "Copy & Open Google". It attempts to copy the text and opens the review page in a new tab.
7. On Google's page, the customer may need to paste the text manually and submit it.

IMPORTANT
- This is a free, local JavaScript phrase-combination generator, not an AI model.
- Reviews can be edited before copying.
- Clipboard access works best on localhost or an HTTPS-hosted website. If a browser blocks clipboard access, the website selects the text so the user can copy with Ctrl+C.
- Pop-up settings can block the Google page. If so, use the visible "Open" link.
- Google does not guarantee a review box will auto-fill from a copied text. The customer must paste and submit it.
- Do not fabricate experiences, offer rewards for positive reviews, or pressure customers. Publish only honest feedback based on a real visit or service.
- Google Fonts are loaded online; system fonts are used as a fallback.
